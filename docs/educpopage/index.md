# Souscriptions — la doc educpopage

Ce site est un outil de validation : chaque page décrit **une fonctionnalité
du module par le geste métier** qui la porte au quotidien, et se relit avec
les facturistes plutôt que dans le code. Là où une règle mérite d'être
confirmée, un encart **« À valider avec vous »** le signale explicitement.

Une fois les pages relues et validées, ce même site devient la base d'une
**référence durable** — le lieu où on vient vérifier « comment ça marche »
sans rouvrir le code.

## La structure de chaque page

Chaque geste métier se lit en quatre étages, du plus lisible au plus
technique :

1. **En deux mots** — ce que fait la fonctionnalité, en une phrase.
2. **Le geste au quotidien** — ce qu'on voit et ce qu'on clique, côté
   facturiste.
3. **Les règles du jeu** — les cas particuliers, les garde-fous, ce qui est
   volontairement interdit.
4. **Sous le capot** — le mécanisme réel, pour qui veut aller plus loin.

## Les 9 gestes métier

La nav à gauche liste les 9 gestes couverts : le contrat, les prix, la
facturation du mois, la régularisation, l'encaissement, le raccordement, le
portail client, les mails et le consentement des données de conso.
